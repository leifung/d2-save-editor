工作原理

  • 本工具按 Diablo II 1.13c 存档格式逐位解析文件：固定 765 字节头部 → gf 人物属性段 → if 技能段 → JM 物品列表 → 尸体 → jf 雇佣兵 → kf 石魔。
  • 解析时为每个可编辑数值记录位偏移量与位宽。修改已有数值时只把这些位写回文件副本（原位位改写，文件大小不变）；随后重算文件长度与校验和（D2S 标准累加算法），未知字节原样保留。
  • 魔法属性按 1.13c 的 ItemStatCost 位宽（Save Bits / Save Add / Save Param Bits / Encode）解码与编码，已处理充能技能、技能参数、技能系、多属性组、8.8 定点生命等特殊情况。
  • 添加技能 / 词条时，按 9 位属性 ID + 参数位 + 数值位生成新的属性位段，插入到目标装备魔法属性列表的正确位置（保持属性 ID 升序），丢弃旧的对齐填充并重新按字节对齐，再把镶嵌物等后续字节原样接回；各物品段、尸体、雇佣兵、石魔段按字节重新拼接。因此文件会变长，但其它数据一位不动。
  • 物品、魔法词缀、暗金与套装名称取自游戏中文版字符串表（string.tbl / expansionstring.tbl / patchstring.tbl），已由繁体转为简体。技能名同样来自官方字符串表并按英文名对齐技能 ID。列表与详情同时保留英文原名，搜索框支持中英文混搜；个别未被汉化的条目自动回退英文。

添加技能 / 词条属性

  • 在「装备属性」页选中一件装备，详情页底部有「＋ 添加技能 / 词条属性」面板。可选 239 种可写属性，按「技能 / 常用词条 / 其它 / 高级 / 全部」分类，支持中文名、英文名或 ID 搜索。
  • 技能类包含：+所有技能等级、+单项技能等级、+职业技能等级、+技能系等级、攻击/命中/击杀/受击/升级时施放技能、充能技能等。选择技能时下拉框为官方中文技能名，充能技能可分别设置当前/最大充能次数。
  • 点「加入待添加列表」后可继续选其它属性或切换到别的装备，所有待添加项一次性写入；保存前可逐条移除或清空。底部状态栏显示待添加条数。
  • 新增属性只对所选装备生效。简易物品（金币、药水、耳朵等）没有属性列表，界面会禁用添加。保存后重新载入新文件即可像普通属性一样继续编辑新增的数值。
  • 部分属性有游戏侧限制（例如只对特定物品类型生效、需要对应技能或职业），写入合法但游戏内可能不显示；「高级」分类里的 by-time、灵气、怪物类型等属性使用原始编码，请谨慎使用。

使用步骤

  • 先备份原存档（例如复制一份 你的角色.d2s.bak），再修改。
  • 在「人物属性」页改人物数值；在「装备属性」页改现有数值，并用详情页底部的面板添加技能 / 词条。底部状态栏会同时显示改动项数与待添加条数。
  • 点「保存并下载」，得到 原文件名_mod.d2s（若新增了属性，文件会比原来大一些），改名回原文件名后覆盖游戏 Save 目录中的原档即可。
  • 建议退出游戏后再替换文件，避免游戏退出时回写覆盖修改结果。

适用范围与注意

  • 核心修改目标是 .d2s 人物存档。同目录下的 .d2x / .key / .ma0~.ma3 / .map / .UDI 属于共享仓库、按键与地图数据，本工具不处理。
  • 不支持 1.14 / 重制版（D2R）、以及 .d2i 等独立物品文件；加载时会校验魔数与版本。
  • 「全部设为上限」会把等级也设为位宽上限（127），游戏内可能异常，建议等级用「等级设为 99」。
  • 若原始存档校验和本就不匹配（曾被其他工具改过），仍可编辑；保存时会重算为正确值。
