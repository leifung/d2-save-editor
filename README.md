# D2 Save Editor · 暗黑破坏神 II 1.13c 存档修改器

单文件、纯离线的浏览器工具，用于直接编辑《暗黑破坏神 II》1.13c 的 `.d2s` 人物存档：修改人物属性与装备属性，并可**给装备新增原本没有的技能与词条属性**。

打开 `index.html` 即可使用：无需安装、无需联网、无需后端，存档全程只在浏览器本地处理，不会上传到任何服务器。

- **适用版本**：Diablo II 1.13c（Lord of Destruction，存档版本 `0x60`）
- **处理对象**：仅 `.d2s` 人物存档。共享仓库 / 地图缓存（`.d2x`、`.key`、`.ma0~3`、`.map`、`.UDI` 等）不在范围内
- **界面语言**：简体中文；物品与词缀名取自官方中文版游戏字符串表，英文原名保留在详情标题与列表悬停提示中

## 功能

**人物属性**：力量、敏捷、体力、精力、剩余属性点、剩余技能点、生命、法力、耐力、等级、经验、身上金币、仓库金币。带合法范围限制与快捷预设（等级 99、金币全满等）；等级会同步写入文件头。

**装备属性**：角色身上、镶嵌物、雇佣兵、尸体、石魔上的全部物品逐件展开；每条魔法属性显示中文名 + 英文名 + 原值 + 合法范围，可直接改数值。物品等级、防御、耐久、数量、孔数等基础字段同样可编辑。支持中英文混合搜索。

**新增技能 / 词条属性**（v2 起）：可从 **239 种可写属性**中选择，按「技能 / 常用词条 / 其它 / 高级 / 全部」分类，支持中文名、英文名或 ID 搜索。

- 技能类：`+所有技能等级`、`+单项技能等级`（选具体技能）、`+职业技能等级`、`+技能系等级`（选职业 + 技能系）、`攻击/命中/击杀/受击/升级时施放技能`（技能 + 等级 + 几率）、`充能技能`（技能 + 等级 + 当前/最大充能）、赋予灵气等。
- 词条类：力量/敏捷/体力/精力、生命/法力、四系抗性、增强伤害/防御、攻击/施法/移动速度、MF/GF、压碎打击、致命攻击、撕开伤口、无法冻结、各类吸收与穿透等。
- 技能下拉使用**官方中文技能名**；多属性组（如增强伤害的最小/最大）会同时生成两个输入。
- 待添加项可跨装备累积、逐条删除，保存时一次性写入；不合法的数值会按位宽自动限制。

**安全写入**：

- *修改已有数值* 采用原位位覆写（in-place bit patching），只改动目标数值所在的位区间 —— 文件大小不变、未编辑字段零改动、不破坏未知字节；8.8 定点生命 / 法力 / 耐力的原始小数位也会保留。
- *新增属性* 会按 9-bit 属性 ID 升序插入目标装备的魔法属性列表，丢弃旧的对齐填充并重新按字节对齐，再把镶嵌物等后续字节原样接回；只重建目标装备的位流，其余装备与人物数据一位不动，因此**文件会相应变长**。
- 两种情况都会自动重算 D2S 校验和与文件长度，保存前还会重新解析一遍做结构校验。

加载时会校验魔数、版本、解析是否精确到达 EOF、校验和是否有效，四项结果直接显示在界面上。

## 使用方法

1. **先备份原始存档**（重要）。
2. 下载本仓库的 `index.html`，双击用 Edge 或 Chrome 打开；也可使用下方 GitHub Pages 在线地址。
3. 点击「选择文件」载入 `.d2s`。
4. 在「人物属性」页改人物数值；在「装备属性」页改现有数值，或用详情页底部的「＋ 添加技能 / 词条属性」面板（也可点详情头部的快捷按钮跳转）新增属性。
5. 点「保存并下载」，浏览器下载 `原文件名_mod.d2s`（新增过属性时文件会比原来略大）。**完全退出游戏后**，把它改名回原文件名，覆盖游戏 `Save` 目录下的原文件。
6. 进入游戏检查；若出现异常，用第 1 步的备份还原。想继续编辑新增的属性，重新载入保存后的文件即可。

## 实现原理

D2S 的物品段是 LSB-first 的位流，不是字节对齐结构：

- 用 `BitReader` 逐位读取；魔法属性为 9-bit ID 循环，遇 `0x1FF` 结束；每条属性按 1.13c `ItemStatCost` 的 Save Bits / Save Add / Save Param Bits / Encode 解码。
- 解析时为每个可编辑数值记录一个**位锚点**：绝对位偏移、位宽、解码元数据。写入时只覆写这些位区间。
- 生命 / 法力 / 耐力是 8.8 定点数，编辑时保留低 8 位小数。
- **结构重建**：解析时同时记录每件物品的起始字节、位流结束（字节对齐）位置与结束字节，以及每个属性列表的结束符位置。新增属性时按 dschu012 的 `values` 顺序编码（技能触发类 `param = level | skillId << 6`，充能类值再按 8+8 位拆当前/最大充能，技能系 `param = tab | class << 3`），插到属性 ID 升序的正确位置，重新对齐后拼接各物品段、尸体、雇佣兵、石魔段。
- 保存时按标准算法重算校验和（对除校验和字段外的全部字节累加，含进位），并同步文件长度字段。

解析器以 dschu012/d2s 的 TypeScript 实现为权威参考逐行移植。开发中遇到的位流错位，根因是物品结构分支处理有误（Rare/Crafted 名称循环、防御与耐久字段、尸体段结构），而非属性位宽常量不对。

## 从源码重建

只需要 Python 3，无第三方依赖：

```bash
python3 build_html.py                 # 生成 index.html
python3 build_html.py my-tool.html    # 或指定输出文件名
```

`build_html.py` 读取同目录下的 `tool_template.html`、`d2s_engine.js`、`d2s_data.json`。数据已随仓库提供，这条链路可完全离线复现。

回环测试（需要一个 1.13c 的 `.d2s`）：

```bash
python3 roundtrip.py /path/to/your/save.d2s
```

`core.py` / `export_data.py` / `gen_item_cn.py` 属于**数据再生成工具**，需要额外外部输入，不是运行本工具的依赖：

- `core.py`、`export_data.py`、`gen_add_meta.py` 需要 dschu012/d2s 的 `ref/d2s/src_data_versions_96_constant_data.ts`（v96 常量表）。
- `gen_item_cn.py`、`gen_add_meta.py` 需要中文版游戏 MPQ 解出的三张 `zh_*.tbl`，以及 `pip install zhconv`。TBL 的 MPQ 提取用到 PKWARE implode 解压实现，出于许可原因未包含在本仓库。

新增属性的测试（需要 Node 22 与一个 1.13c 存档）：

```bash
node test_add_props.js /path/to/your/save.d2s
```

## 数据来源与致谢

- 文件格式与常量表：[dschu012/d2s](https://github.com/dschu012/d2s)，v96 常量（源自完整版 `ItemStatCost.txt`，含 Save Param Bits / CSvBits / Signed 列）。
- 中文物品名与中文技能名：中文版游戏 `Patch_D2.mpq` 内 `data\local\LNG\chi\` 下的 `string.tbl` / `expansionstring.tbl` / `patchstring.tbl`，为 UTF-8 繁体，已统一转简体并去除汉化时拼接在后面的英文原名。技能名按汉化表括号中保留的英文名反查技能 ID（TBL 的 `skillname<N>` 编号与存档技能 ID 在部分职业区间存在偏移，不能直接按序号对应）。
- MPQ 解压参考：PKWARE implode 的 Python 实现 `pwexplode.py`（Sven Kochmann，GPL-3.0），仅用于离线提取字符串表；其代码未包含在本仓库，也不是运行时依赖。

- 3 个不同的真实存档均精确解析到 EOF、校验和有效；中文物品名覆盖率 100%。

- 全量位锚点按显示值重写后，除校验和字段外逐字节完全一致。
- 注意：以上为格式层面的验证。**未在真实游戏客户端中逐一实测每种新增属性**，部分属性受游戏侧条件约束可能不显示；修改前务必备份。
