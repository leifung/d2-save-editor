工作原理

  • 本工具按 Diablo II 1.13c 存档格式逐位解析文件：固定 765 字节头部 → gf 人物属性段 → if 技能段 → JM 物品列表 → 尸体 → jf 雇佣兵 → kf 石魔。
  • 解析时为每个可编辑数值记录位偏移量与位宽；保存时只把这些位写回文件副本，随后重算文件长度与校验和（D2S 标准累加算法）。因此不改变装备结构、不增删属性、文件大小恒定，未知字节原样保留。
  • 魔法属性按 1.13c 的 ItemStatCost 位宽（Save Bits / Save Add / Save Param Bits / Encode）解码，已处理充能技能、技能参数、8.8 定点生命等特殊情况。
  • 物品、魔法词缀、暗金与套装名称取自游戏中文版字符串表（string.tbl / expansionstring.tbl / patchstring.tbl），已由繁体转为简体。列表与详情同时保留英文原名，搜索框支持中英文混搜；个别未被汉化的条目自动回退英文。

使用步骤

  • 先备份原存档（例如复制一份 leiya.d2s.bak），再修改。
  • 分别在「人物属性」「装备属性」页修改数值，底部会显示改动项数。
  • 点「保存并下载」，得到 原文件名_mod.d2s，改名回原文件名后覆盖游戏 Save 目录中的原档即可。
  • 建议退出游戏后再替换文件，避免游戏退出时回写覆盖修改结果。

适用范围与注意

  • 核心修改目标是 .d2s 人物存档。同目录下的 .d2x / .key / .ma0~.ma3 / .map / .UDI 属于共享仓库、按键与地图数据，本工具不处理。
  • 不支持 1.14 / 重制版（D2R）、以及 .d2i 等独立物品文件；加载时会校验魔数与版本。
  • 「全部设为上限」会把等级也设为位宽上限（127），游戏内可能异常，建议等级用「等级设为 99」。
  • 若原始存档校验和本就不匹配（曾被其他工具改过），仍可编辑；保存时会重算为正确值。
